## Overview

**Assets Handler** is a Windows desktop application built for inspecting, extracting, editing, and replacing assets from Unity AssetBundles and serialized asset files.

It brings essential asset-handling capabilities together in one workspace, making it useful for developers, modders, and users working with Unity-based content.
